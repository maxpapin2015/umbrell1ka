Скриншоты

Так это выглядит в бою

Отрисовка оверлея идёт поверх кадра игры: меню можно возить мышью, страницы листаются колесом, всё перерисовывается в реальном времени.

Как это работает

Три шага, всё на клиенте

DLL цепляется к DXGI Present, рисует оверлей через ImGui и читает только те структуры игры, которые уже лежат в памяти твоего процесса.

01

Хук кадра

Перехват Present в dxgi.dll. Оверлей рисуется в том же кадре, что и игра — без второй очереди и без просадок.

02

Чтение состояния

Герои, крипы, варды, кулдауны и wearables берутся из сущностей и схемы клиента. Сеть не используется вообще.

03

Действие

Клики уходят в окно игры сообщениями Win32, скины — записью defindex в память. Курсор физически не двигается.

Что оверлей не делает

Честный список — чтобы не было сюрпризов после установки.

  • Не ходит на серверы Valve: ни логина, ни отправки инвентаря, ни «активации».
  • Не разблокирует предметы на аккаунте. Владение — факт на сервере, память клиента его не переписывает.
  • Скины видишь только ты: другие игроки получают от сервера обычную модель героя.
Открытый исходный код Без телеметрии Антивирус отключать не нужно

Что делает

  • Меняет то, что уже принадлежит твоему клиенту: камеру, ввод, отрисовку, локальные wearables.
  • Возвращает всё назад при выключении тумблера и при выгрузке DLL — оригинальные значения хранятся в памяти.
  • Работает поверх окна игры в любом режиме — и в матче, и в предпросмотре героя.
Установка

Распаковал — запустил

Готовый путь занимает минуту. Сборка из исходников спрятана ниже, она нужна только если правишь код сам.

01

Распаковать архив

В ZIP лежат umbrell1ka.dll и injector.exe. Оба файла должны быть в одной папке — инжектор ищет DLL рядом с собой.

02

Запустить инжектор

Правый клик по injector.exe → «Запуск от имени администратора». Без прав не откроется хэндл процесса.

03

Выбрать режим

1 — запустить Dota 2 через Steam и заинжектить в неё. 2 — заинжектить в уже запущенную игру.

04

Открыть меню

INSERT — меню, END — выгрузка. Клавиши меняются на странице Binds; настройки сохраняются между запусками.

Одна копия игры: инжект в живой процесс, не второй dota2.exe
Для разработчиков — сборка из исходников

Нужны Visual Studio Build Tools (MSVC, x64) и Python — только для вспомогательных скриптов. Оба батника сами находят vcvars64 через vswhere.

:: DLL → build\umbrell1ka.dll
build.bat

:: инжектор → build\injector.exe (запросит UAC)
build_inj.bat

:: запуск без меню, по конкретному PID
build\injector.exe --pid <PID>

Если линковка падает с LNK1104 — игра держит DLL. Выгрузи оверлей по END и повтори сборку, процесс убивать не нужно.

FAQ

Вопросы, которые задают первыми

Внешний вид героя складывается из предметов, которые выдаёт сервер. Оверлей меняет defindex уже надетых wearables в памяти клиента — модель пересобирается локально. Другие игроки получают от сервера твой настоящий набор, поэтому видят стандартную модель. Это ограничение архитектуры игры, а не настройка.

В самом оверлее — да. Каталог скинов собран из items_game.txt целиком: 9 576 предметов по всем героям и слотам, включая платные иммортали и сеты, которые на аккаунте не куплены. Всё это можно выбрать в Skin Picker и надеть на героя — сервер и профиль при этом не трогаются.

Сетка арсенала внутри клиента Valve — другое: она строится из предметов, которые сервер прислал аккаунту. Её вид можно подменить только хуком клиентских структур UI, и это чисто косметика — предмет не станет купленным ни в профиле, ни в инвентаре.

Если запись всё же нужна — выгрузи DLL по END и проверь, что хук снят. Скрытого режима «только для меня» в оверлее нет, и обещать его было бы враньём.

Инжектор пишет в чужой процесс и запрашивает права администратора — на это поведение эвристики и реагируют. Отключать защиту не нужно: добавь папку с оверлеем в исключения Windows Defender.

Всё, что делает инжектор: находит dota2.exe, открывает процесс и вызывает LoadLibrary с путём к DLL. Никаких сетевых запросов и автозапуска в нём нет.

Офсеты схемы и сущностей лежат в одном месте. Большинство патчей ломают только их — тогда обновляется таблица, а логика остаётся. Консольные команды ищутся по имени, а не по адресу, поэтому их переносить не нужно.

Только для самой Dota 2. Оверлей не делает ни одного исходящего запроса: ни телеметрии, ни проверки лицензии, ни загрузки конфигов. Всё, что он читает и пишет, находится в твоём процессе.
